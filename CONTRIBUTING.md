# Contributing

Thanks for helping. Open an issue first for anything bigger than a fix, so we can agree on the direction.

- How to run the tests, keep the plugin and extension copies in sync, and make a release is in the
  ["Working on this repository"](README.md#working-on-this-repository) section of the README.
- The format is [`SPEC.md`](SPEC.md). A change to what the tool does starts with the clause or the text in `SPEC.md`, and
  `tools/py/test_sor_docs.py` fails when a document and the code disagree.
- Report security problems privately, as described in [`SECURITY.md`](SECURITY.md).
- Contributions are under the licenses in [`LICENSE.md`](LICENSE.md): CC BY 4.0 for the spec text, MIT for the tools.
